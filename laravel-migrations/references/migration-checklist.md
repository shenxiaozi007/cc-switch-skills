# Migration Checklist（本仓库）

## 变更设计
- [ ] 变更类型明确（新表/字段/索引/回填）
- [ ] 文件命名清晰且可读
- [ ] 已搜索同模块、同表、同字段、同索引历史 migration
- [ ] 是否需要按专题目录归档已确认；专题目录优先复用同模块最近目录
- [ ] 主键、时间字段、软删字段写法已对齐同模块历史或已说明采用新规范

## up/down 对称性
- [ ] `up()` 完整实现目标变更
- [ ] `down()` 可安全回滚当前变更
- [ ] 索引名、字段名、表名前后一致
- [ ] 新增字段带索引时，回滚顺序为先删索引再删字段
- [ ] 新建表 `down()` 的 `dropIfExists()` 表名和 `up()` 的 `Schema::create()` 完全一致

## 执行与发布
- [ ] 已规划 `--path` 指定执行
- [ ] 专题目录文件的 `--path` 已包含子目录
- [ ] 已确认环境与分支对应（local/tests/production）
- [ ] 已评估线上锁表与执行窗口
- [ ] 已评估代码发布与 migration 先后顺序

## 风险控制
- [ ] 新字段默认值/可空策略合理
- [ ] 高风险删除操作有分阶段方案
- [ ] 数据回填策略可重跑、可回滚
- [ ] 唯一索引已确认历史数据无重复
- [ ] 大表加索引已确认执行窗口或在线 DDL 方案
